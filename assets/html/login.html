Only trust websites on, or from https://tdrbot.github.io. Do NOT trust links ending in domains similar to '.github.io' that are NOT 'github.io,' if this is embedded as 'about:blank' or anywhere online (this should ONLY be viewed in ELL itself), if you're accessing this page from a 3rd party/modded ELL client, or if this warning is absent entirely.
